# معرض الأعمال الشخصي (Portfolio) - عبد الرحمن برهام

موقع معرض أعمال شخصي حديث، تفاعلي، ومتعدد اللغات (عربي / إنجليزي) لمصمم ومطور المواقع **عبد الرحمن برهام**.

---

## 🌟 المميزات والتقنيات

- **دعم ثنائي اللغة (RTL / LTR):** تبديل فوري بين اللغة العربية والإنجليزية مع تعديل اتجاه الصفحة والخطوط تلقائياً.
- **تأثيرات زجاجية وحركية حديثة (Glassmorphism & Ambient Glow):** خلفيات مضيئة وتصميم حديث باستخدام أحدث معايير CSS.
- **تجاوب كامل (Responsive Design):** متوافق تماماً مع جميع الشاشات (الهواتف المحمولة، الأجهزة اللوحية، وأجهزة الشاشة العريضة).
- **وظائف تفاعلية:**
  - نسخ رقم الهاتف بنقرة واحدة مع ظهور إشعار مؤقت (Toast Notification).
  - التوجيه المباشر لواتساب والاتصال الهاتفي.
